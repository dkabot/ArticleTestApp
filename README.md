# JSON Article Loader Test App
This repository contains a test app environment for a JSON-based article loader.  
The available options in the format are described in schema.json; the only one not implemented is local video (which should be fairly straightforward).

YouTube video playback is achieved via [YouTubePlayerKit](https://github.com/SvenTiigi/YouTubePlayerKit).  
The text JSON and image assets included in this repo are adapted from [https://retrogamecorps.com/2024/04/28/setting-up-a-handheld-for-children-or-adult-children/](https://retrogamecorps.com/2024/04/28/setting-up-a-handheld-for-children-or-adult-children/) and are owned by Retro Game Corps, used for educational and testing purposes. There is no intent to reproduce such articles in a final product.
